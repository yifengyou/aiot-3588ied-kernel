本项目为瑞芯微 RK3588 平台（彼度云 G98/Z98）设备的固件刷写与维护工具，提供固件刷写、引导顺序配置、存储健康检测、终端访问及在线更新等功能。

📋 功能说明

  • ⚡ 固件刷写 — 支持上传固件镜像刷写到设备存储
  • 🔀 引导顺序 — 配置 U-Boot bootcmd 启动顺序
  • 💾 存储检测 — 调用 smartctl/sgdisk 检测存储设备健康状态
  • 📦 更新助手 — 通过 GitHub 在线更新 SPI Recovery 镜像
  • 💻 终端 — 远程 Web Shell 访问设备命令行

备份还原

全盘备份/还原磁盘镜像，使用 gzip 实时压缩，支持边下载边备份、边上传边还原。

💿 全盘备份

选择磁盘后点击备份，浏览器将下载 gzip 压缩的磁盘镜像。整个过程边读边压缩边下载，不占用设备内存。

⚠️ 备份大磁盘可能耗时较长，请确保网络稳定。备份过程中请勿关闭浏览器或断开设备电源。
点击「🔄 刷新磁盘列表」加载可用磁盘
📤 全盘还原

选择之前备份的 .img.gz 压缩镜像和目标磁盘，上传后边解压边写入。整个过程不占用设备内存。

⚠️ 还原操作会覆盖目标磁盘上的所有数据！请仔细确认目标磁盘，误操作将导致数据永久丢失。

🛡️ 防火墙

基于 iptables 的网络访问控制，支持入站规则、转发规则和端口转发（DNAT）。规则存储在自定义链 RKDEV_* 中，不影响系统原有规则。

🌐 网络更新

检测 GitHub 仓库是否有新版本，检测到更新后可一键下载并写入 SPI Flash。

⚠️ 更新写入 SPI Flash 为同步操作，整个过程可能耗时 5-10 分钟。更新期间请勿关闭浏览器、断开电源或重启设备，否则可能导致设备无法启动。更新成功后引导顺序将自动还原为出厂默认值，请更新完成后前往「引导顺序」页面检查并按需调整。
